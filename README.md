## 🚀 Démarrage Rapide

Pour pouvoir exécuter et tester l'application sur votre machine :

### Prérequis

1.  **Visual Studio :** Avoir une version récente de [Visual Studio Community/Professional] installée.
.  **Framework .NET :** Assurez-vous que .NET framework 4.7.2 est installé sur votre machine.

### Exécution

1.  **Cloner le dépôt :**
    ```bash
    git clone https://github.com/news782/WInform-C--App-Gestion-CasernePompier.git
    ```
2.  **Ouvrir la solution :**
    * Naviguez vers le dossier cloné.
    * Ouvrez le fichier de solution (`.sln`) dans Visual Studio.
3.  **Compiler et Exécuter :**
    * Sélectionnez la configuration **Debug** ou **Release**.
    * Appuyez sur **F5** ou sur le bouton **Démarrer** dans Visual Studio.
